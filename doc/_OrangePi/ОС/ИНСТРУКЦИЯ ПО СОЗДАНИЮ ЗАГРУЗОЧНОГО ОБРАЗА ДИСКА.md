# Создание загрузочного образа диска для Orange Pi 5 Plus

**Назначение документа:** Данная инструкция описывает процедуру создания резервной копии операционной системы в виде файла-образа для последующего восстановления системы или развертывания на дополнительных устройствах.

---

## Требования к системе

- Orange Pi 5 Plus с установленной операционной системой
- SD-карта объемом не менее 8 ГБ  
- Доступ к командной оболочке с правами администратора

---

## Порядок выполнения

### Этап 1: Подготовка дисковых разделов

#### 1.1 Проверка исходного раздела
**Назначение:** Определение объема данных основной системы

```bash
df -h | grep nvme0n1p1
```

#### 1.2 Подготовка SD-карты
**Назначение:** Форматирование носителя и подготовка к записи системных данных

**Форматирование SD-карты:**
```bash
sudo mkfs.ext4 /dev/mmcblk1p1
```

**Создание директории монтирования:**
```bash
sudo mkdir /mnt/dst
```

**Монтирование SD-карты:**
```bash
sudo mount /dev/mmcblk1p1 /mnt/dst
```

### Этап 2: Копирование системы на SD-карту

**Назначение:** Создание полной копии операционной системы на съемном носителе

```bash
sudo rsync -aAXv --delete --exclude={"/dev/*","/proc/*","/sys/*","/tmp/*","/run/*","/mnt/*","/media/*","/lost+found/*"} / /mnt/dst/
```

**Время выполнения:** 15-30 минут в зависимости от объема данных

### Этап 3: Настройка загрузочных параметров

#### 3.1 Получение идентификатора устройства
**Назначение:** Определение уникального идентификатора SD-карты для конфигурации загрузчика

```bash
sudo blkid /dev/mmcblk1p1
```

**Примечание:** Сохраните значение UUID для последующего использования

#### 3.2 Конфигурирование системных файлов
**Назначение:** Настройка системы для загрузки с SD-карты

**Редактирование файла fstab:**
```bash
sudo nano /mnt/dst/etc/fstab
```

**Редактирование конфигурации загрузчика:**
```bash
sudo nano /mnt/dst/boot/armbianEnv.txt
```

**Требование:** В указанных файлах необходимо заменить существующий UUID на новый, полученный на предыдущем шаге

#### 3.3 Завершение конфигурации
**Назначение:** Применение изменений и безопасное отключение носителя

**Синхронизация данных:**
```bash
sudo sync
```

**Отключение SD-карты:**
```bash
sudo umount /mnt/dst
```

**Проверка целостности файловой системы:**
```bash
sudo fsck.ext4 -f /dev/mmcblk1p1
```

### Этап 4: Создание файла образа системы

#### 4.1 Тестирование загрузки с SD-карты
**Назначение:** Проверка корректности функционирования системы при загрузке с съемного носителя

1. Выполните перезагрузку Orange Pi 5 Plus
2. Убедитесь в успешной загрузке системы с SD-карты  
3. Проведите тестирование основных системных функций

#### 4.2 Создание файла образа
**Назначение:** Формирование файла-образа для последующего использования

**Предварительное условие:** Загрузка с основного накопителя

```bash
sudo dd if=/dev/mmcblk1 of=backup.img bs=4M status=progress
```

**Время выполнения:** 10-20 минут

#### 4.3 Сжатие образа
**Назначение:** Оптимизация размера файла образа

**Установка прав выполнения для скрипта:**
```bash
chmod +x opishrink.sh
```

**Выполнение сжатия:**
```bash
sudo ./opishrink.sh backup.img
```

---

## Результат выполнения процедуры

По завершении процедуры будут созданы следующие файлы:

- **backup.img** - полный образ системы
- **backup.img.xz** - сжатый образ (при использовании скрипта opishrink.sh)

---

## Важные замечания

- **Резервное копирование:** Рекомендуется регулярно создавать новые образы после внесения значительных изменений в систему
- **Дисковое пространство:** Необходимо обеспечить достаточный объем свободного пространства для создания образа
- **Права доступа:** Все операции выполняются с правами суперпользователя (sudo)

---

## Устранение неисправностей

- **Ошибка "No space left on device":** Освободите дисковое пространство
- **Ошибка монтирования:** Проверьте правильность подключения SD-карты
- **Система не загружается:** Проверите корректность значений UUID в конфигурационных файлах
