# Настройка Orange Pi 5 Plus для работы с системой ИППП ЛИНИЯ

**Назначение документа:** Данная инструкция описывает процедуру развертывания и настройки операционной системы на мини-компьютере Orange Pi 5 Plus с последующей установкой специализированного программного обеспечения ИППП ЛИНИЯ для измерительного оборудования.

---

## Требования к оборудованию и программному обеспечению

- Orange Pi 5 Plus
- SD-карта объемом не менее 16 ГБ (рекомендуется 32 ГБ)
- SSD-накопитель для Orange Pi (рекомендуется 120+ ГБ)
- Компьютер с доступом в Интернет
- Кабель питания для Orange Pi
- Сетевое подключение

---

## Раздел 1: Развертывание операционной системы

### Этап 1: Подготовка загрузочного носителя

#### 1.1 Установка программного обеспечения для записи образа
**Назначение:** Установка специализированного ПО для записи системного образа на SD-карту

1. Откройте веб-браузер
2. Перейдите по адресу: https://balena.io/etcher
3. Загрузите и установите приложение **BalenaEtcher**

#### 1.2 Запись системного образа на SD-карту
**Назначение:** Создание загрузочного носителя с операционной системой

1. **Запуск BalenaEtcher**
2. **Выбор образа:** Нажмите "Flash from file" и укажите файл:  
   `CLEAN_IMAGE_ORANGE_PI_5_PLUS_UBUNTU_24.04_XFCE.img.xz`
3. **Выбор целевого устройства:** Подключите SD-карту и выберите её в качестве целевого носителя
4. **Запуск процедуры записи:** Нажмите "Flash!" и ожидайте завершения операции

**Время выполнения:** 10-15 минут

### Этап 2: Инициализация системы

**Назначение:** Первоначальный запуск и базовая настройка системы

1. Установите подготовленную SD-карту в Orange Pi 5 Plus
2. Подключите кабель питания
3. Подключите периферийные устройства (монитор, клавиатуру, мышь)
4. Включите устройство

**Время загрузки:** 2-3 минуты при первом запуске

## Раздел 2: Конфигурирование сетевого подключения

### Этап 3: Настройка SSH для удаленного доступа

**Назначение:** Конфигурирование SSH-сервера для обеспечения удаленного управления устройством

#### 3.1 Запуск командной оболочки
1. Используйте комбинацию клавиш **Ctrl + Alt + T** или найдите приложение "Terminal" в системном меню
2. Откроется интерфейс командной строки

#### 3.2 Конфигурирование SSH-сервера
**Назначение:** Настройка параметров SSH для обеспечения удаленного доступа

**Применение конфигурации SSH:**
```bash
cat << EOF | sudo tee /etc/ssh/sshd_config > /dev/null
Include /etc/ssh/sshd_config.d/*.conf
Port 22
AddressFamily inet
ListenAddress 0.0.0.0
PermitRootLogin yes
PasswordAuthentication yes
UsePAM yes
AllowTcpForwarding yes
X11Forwarding no
AcceptEnv LANG LC_*
Subsystem sftp /usr/lib/ssh/sftp-server
EOF
```

#### 3.3 Конфигурирование сетевого интерфейса
**Назначение:** Настройка сетевых параметров для обеспечения подключения к Интернет

**Сброс конфигурации сетевого интерфейса:**
```bash
sudo ip addr flush dev enP3p49s0
```

**Активация сетевого интерфейса:**
```bash
sudo ip link set enP3p49s0 up
```

**Назначение IP-адреса:**
```bash
sudo ip addr add 192.168.137.2/24 dev enP3p49s0
```

**Конфигурирование маршрутизации:**
```bash
sudo ip route add default via 192.168.137.1
```

**Настройка DNS-сервера:**
```bash
echo "nameserver 8.8.8.8" | sudo tee /etc/resolv.conf > /dev/null
```

**Перезапуск SSH-службы:**
```bash
sudo systemctl restart sshd
```

## Раздел 3: Миграция системы на SSD-накопитель

### Этап 4: Подготовка SSD-накопителя

**Обоснование:** Использование SSD-накопителя обеспечивает значительное повышение производительности системы по сравнению с SD-картой

#### 4.1 Диагностика подключенных накопителей
**Назначение:** Идентификация доступных устройств хранения данных

```bash
lsblk
```

**Ожидаемый результат:**
```
NAME        MAJ:MIN RM   SIZE RO TYPE MOUNTPOINTS
mtdblock0    31:0    0    16M  0 disk
mmcblk1     179:0    0  58.2G  0 disk    ← SD-карта
└─mmcblk1p1 179:1    0  57.6G  0 part /var/log.hdd
                                      /
zram0       252:0    0   3.9G  0 disk [SWAP]
zram1       252:1    0    50M  0 disk /var/log
nvme0n1     259:0    0 119.2G  0 disk  ← SSD-накопитель
```

#### 4.2 Клонирование системы на SSD-накопитель
**Назначение:** Создание полной копии системы на высокопроизводительном накопителе

```bash
dd if="/dev/mmcblk1" of="/dev/nvme0n1" bs=4M status=progress
```

**Время выполнения:** 15-30 минут

#### 4.3 Конфигурирование разделов на SSD
**Назначение:** Оптимизация использования дискового пространства

**Запуск редактора разделов:**
```bash
gdisk "/dev/nvme0n1"
```

**Обновление таблицы разделов:**
```bash
partprobe "/dev/nvme0n1"
```

**Расширение раздела:**
```bash
expect <<EOF
    spawn sudo parted /dev/nvme0n1 resizepart
    expect "Fix/Ignore?" { send "Fix\r" }
    expect "Partition number?" { send "1\r" }
    expect "End?  [*]?" { send "100%\r" }
    expect eof
EOF
```

**Применение изменений:**
```bash
sudo partprobe "/dev/nvme0n1"
```

**Расширение файловой системы:**
```bash
sudo resize2fs "/dev/nvme0n1p1"
```

#### 4.4 Переконфигурирование загрузчика
**Назначение:** Настройка системы для загрузки с SSD-накопителя

**Получение идентификаторов устройств:**
```bash
blkid
```

**Примечание:** Сохраните значения UUID для nvme0n1p1 и mmcblk1p1

**Обновление конфигурационных файлов:**
```bash
sudo sed -i "s|UUID={UUID mmcblk1p1}|UUID={UUID nvme0n1p1}|g" /etc/fstab
sudo sed -i "s|UUID={UUID mmcblk1p1}|UUID={UUID nvme0n1p1}|g" /boot/armbianEnv.txt
```

**Примечание:** Замените {UUID mmcblk1p1} и {UUID nvme0n1p1} на фактические значения

**Перезагрузка системы:**
```bash
reboot
```

## Раздел 4: Установка программного обеспечения ИППП ЛИНИЯ

### Этап 5: Подготовка операционной среды

#### 5.1 Получение привилегий суперпользователя
**Назначение:** Получение необходимых прав доступа для установки системного ПО

```bash
sudo su - root
```

#### 5.2 Обновление системы
**Назначение:** Установка актуальных обновлений безопасности и системных компонентов

**Обновление индекса пакетов:**
```bash
apt-get update
```

**Установка доступных обновлений:**
```bash
apt-get upgrade -y
```

**Время выполнения:** 5-10 минут

#### 5.3 Установка базового программного обеспечения
**Назначение:** Установка инструментов, необходимых для загрузки и управления исходным кодом

**Установка системы контроля версий Git:**
```bash
apt install git
```

**Установка файлового менеджера:**
```bash
apt install mc
```

### Этап 6: Развертывание приложения

#### 6.1 Получение исходного кода
**Назначение:** Загрузка исходного кода системы ИППП ЛИНИЯ из репозитория

```bash
git clone https://github.com/Sasha7b9Work/Linia.git
```

#### 6.2 Установка зависимостей
**Назначение:** Установка библиотек и компонентов, необходимых для функционирования ИППП ЛИНИЯ

**Переход в директорию скриптов:**
```bash
cd Linia/sources/scripts/arm64
```

**Установка прав выполнения:**
```bash
chmod +x install_soft_arm64.sh
```

**Запуск процедуры установки:**
```bash
./install_soft_arm64.sh
```

**Время выполнения:** 10-20 минут

#### 6.3 Компиляция приложения
**Назначение:** Сборка исполняемого файла из исходного кода

**Установка прав выполнения для скрипта сборки:**
```bash
chmod +x full_build_arm64.sh
```

**Запуск процедуры сборки:**
```bash
./full_build_arm64.sh
```

**Время выполнения:** 15-30 минут

### Этап 7: Запуск приложения

#### 7.1 Переход в рабочую директорию
```bash
cd ../../generated/Linia2
```

#### 7.2 Запуск системы ИППП ЛИНИЯ
```bash
./Linia2
```

## Устранение неисправностей

### Недостаток дискового пространства
**Решение:**
```bash
# Очистка кэша пакетного менеджера
apt-get clean

# Удаление неиспользуемых пакетов
apt-get autoremove
```

### Ошибки установки пакетов
**Решение:**
```bash
# Обновление индекса пакетов
apt-get update

# Исправление зависимостей
apt-get install -f
```

### Ошибки запуска приложения
**Решение:**
```bash
# Проверка прав доступа к файлу
chmod +x ./Linia2

# Проверка библиотечных зависимостей
ldd ./Linia2
```
